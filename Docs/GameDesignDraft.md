# 카드팩 로그라이크 게임 기획서 초안

> 프로젝트명: **CardOpen** (가제)  
> 문서 버전: 0.1  
> 작성 기준: 2026-08-03 현재 구현 빌드  
> 대상 플랫폼: PC·모바일 웹 브라우저(Unity WebGL)

## 1. 게임 개요

### 한 줄 소개

3D 카드팩을 직접 뜯고 카드를 한 장씩 공개하며, 뽑은 카드의 점수와 덱 능력의 연쇄 작용으로 라운드 목표 점수를 돌파하는 비전투 카드팩 로그라이크.

### 장르

- 카드팩 개봉 시뮬레이션
- 점수 기반 덱 빌딩 로그라이크
- 짧은 세션형 확률·시너지 게임
- 전투 없음

### 핵심 재미

1. 실제 팩을 만지는 듯한 개봉 손맛
2. 다음 카드의 색·숫자·등급을 기다리는 기대감
3. 5장짜리 작은 덱에서 시너지를 압축하는 선택
4. 카드 능력, 장착, 공명, 합성, 성장으로 점수가 폭발하는 과정
5. 매 라운드 높아지는 목표 점수를 넘기는 긴장감

## 2. 게임의 핵심 방향

### 디자인 원칙

- **개봉 자체가 플레이여야 한다.** 팩과 카드는 단순 버튼이 아니라 직접 드래그하고 회전시키는 3D 오브젝트다.
- **모든 공개에는 의미가 있어야 한다.** 카드의 등급뿐 아니라 색, 숫자, 태그, 홀로그램 여부가 덱 능력과 연결된다.
- **덱은 작고 결정은 무거워야 한다.** 기본 덱은 5칸뿐이며 보관, 교체, 순서 변경, 장착, 합성을 통해 공간 효율을 높인다.
- **전투 대신 점수 엔진을 만든다.** 플레이어는 공격력이나 체력이 아니라 발동 횟수, 점수 보너스, 스택과 생성 효과를 설계한다.
- **확률은 선택으로 보완한다.** 팩 2택, 봉입 카드 미리 보기, 덱 교체를 통해 완전한 운 게임이 되지 않게 한다.

## 3. 핵심 플레이 루프

1. 첫 카드팩 또는 두 개의 후보 팩 중 하나를 선택한다.
2. 팩 윗부분을 드래그해 포장을 뜯는다.
3. 카드가 앞면으로 공개되며 기본 점수와 덱 능력 점수를 획득한다.
4. 카드를 드래그해 다음 카드로 넘긴다.
5. 넘긴 카드는 빈 덱 슬롯에 자동 보관되거나, 조건이 맞으면 기존 카드와 합쳐지거나 자동 장착된다.
6. 필요하면 현재 카드를 덱의 특정 슬롯으로 드래그해 교체하고, 덱 안의 카드를 재배치한다.
7. 팩의 모든 카드를 공개하면 다음 팩 2택으로 이동한다.
8. 3팩마다 라운드 점수를 판정한다.
9. 목표 달성 시 라운드 점수를 초기화하고 다음 라운드로 진행한다. 실패 시 게임 오버다.
10. 6라운드를 모두 통과하면 런 클리어다.

## 4. 런과 라운드 구조

### 기본 구조

- 한 라운드: 3팩
- 전체 라운드: 6개
- 최대 런 길이: 18팩
- 첫 팩: `이야기 꼬리` 고정
- 이후: 서로 다른 카드팩 후보 2개 중 하나 선택
- 총점과 라운드 점수는 별도로 관리
- 총점은 런 전체에서 누적
- 라운드 점수는 목표 달성 후 0으로 초기화

### 라운드별 요구 점수

| 라운드 | 요구 점수 |
|---:|---:|
| 1 | 5,000점 |
| 2 | 10,000점 |
| 3 | 20,000점 |
| 4 | 35,000점 |
| 5 | 60,000점 |
| 6 | 100,000점 |

### 성공과 실패

- 세 번째 팩을 모두 공개한 시점에 해당 라운드 점수를 검사한다.
- 요구 점수 미달이면 즉시 게임 오버 화면으로 이동한다.
- 6라운드 목표를 모두 달성하면 최종 결과 화면으로 이동한다.
- 결과 화면에서는 최종 점수와 완성 덱을 확인할 수 있다.

## 5. 카드팩 시스템

### 팩 상호작용

- 기본 위치에서 정면을 향하는 얇고 유광인 3D 팩으로 표현한다.
- 팩 윗부분을 일정 거리 이상 드래그하면 직선 방향으로 자동 절취된다.
- 짧은 드래그는 팩을 살짝 기울이는 회전 입력으로 처리한다.
- 팩이나 카드 바깥 공간을 드래그하면 오브젝트를 회전해 감상할 수 있다.
- 손을 놓으면 오브젝트가 천천히 기본 각도로 돌아온다.
- 팩이 기울거나 뜯어지는 동안 내부 카드도 함께 움직인다.
- 팩이 열리는 순간부터 내부 카드가 보인다.

### 팩 선택

- 각 팩 종료 후 서로 다른 팩 2개를 제시한다.
- `?` 버튼을 누르면 해당 팩의 봉입 카드 목록을 확인할 수 있다.
- 팩 후보를 회전해도 `?` 버튼은 화면상의 고정 위치를 유지한다.
- 덱은 팩 선택 중에도 확인할 수 있지만 편집은 제한된다.

### 현재 카드팩 풀

| 카드팩 | 기본 장수 | 선택 가중치 | 봉입 카드 종류 | 성격 |
|---|---:|---:|---:|---|
| 이야기 꼬리 | 5 | 1.0 | 26 | 첫 팩이자 범용 입문 팩 |
| 아득하리 | 5 | 1.0 | 26 | 마법·고점 시너지 중심 |
| 별 사다리 | 5 | 1.0 | 26 | 밤하늘 테마의 혼합 팩 |
| 숲마족의 보물 | 5 | 1.0 | 25 | 자연·유물 계열 중심 |
| 꿈나무의 줄기 | 5 | 1.0 | 25 | 자연 성장과 연쇄 중심 |
| 일상의 일화 | 7 | 1.0 | 27 | 저등급 카드가 많고 장수가 많은 팩 |
| 마탑의 현자 | 5 | 1.0 | 25 | 마법·마법사·스택 중심 |
| 영웅 새로운 | 1 | 0.1 | 1 | 희귀하게 등장하는 영웅 특화 팩 |

### 기본 봉입률

대부분의 일반 팩은 다음 등급 분포를 사용한다.

| 등급 | 확률 |
|---|---:|
| 일반 | 60% |
| 고급 | 27% |
| 희귀 | 10% |
| 영웅 | 3% |
| 전설 | 0% |

예외:

- `일상의 일화`: 일반 60%, 고급 30%, 희귀 이상 0%
- `영웅 새로운`: 영웅 100%, 1장 구성
- 팩에 특정 등급 카드가 없으면 실제 추첨에서는 존재하는 등급만 사용한다.
- 팩별 개별 카드 가중치와 일괄 희귀도 확률 적용 기능을 에디터에서 제공한다.
- 팩 간 봉입 카드 유사도가 70% 이상이면 에디터 경고를 표시한다.

## 6. 카드 시스템

### 카드 구성 정보

- 이름과 영문 이름
- 설명과 영문 설명
- 일러스트
- 등급
- 공개 시 무작위로 정해지는 숫자
- 공개 시 무작위로 정해지는 색
- 태그
- 덱 능력
- 장착 슬롯 보유 여부
- 합성 가능 수량

### 숫자와 색

- 숫자: 1, 2, 3, 4, 5, σ(내부 값 6)
- 색: 초록, 파랑, 빨강, 검정, 하양
- 카드팩은 기본적으로 카드마다 숫자와 색을 새로 무작위 결정한다.
- 능력의 색 조건에는 `Self`를 지정할 수 있으며, 이는 능력 보유 카드 자신의 색을 뜻한다.
- 여러 색 조건이 동시에 일치하면 조건별로 발동 횟수를 계산할 수 있다. 예를 들어 빨간 화이리가 빨간 카드를 보면 `Self`와 `Red`가 각각 일치해 능력이 2회 발동한다.
- `빛 이야기`가 활성화되면 하양 카드를 모든 색으로 취급한다.

### 등급과 기본 점수

| 등급 | 기본 점수 | 시각 효과 |
|---|---:|---|
| 일반 | 100점 | 기본 마감 |
| 고급 | 200점 | 카드팩 재질과 유사한 유광 |
| 희귀 | 300점 | 은색 반짝이 |
| 영웅 | 500점 | 보라색 반짝이 |
| 전설 | 500점 | 하늘색 특수 반짝이와 풀아트 |

반짝이와 홀로그램 무늬는 자동으로 흐르지 않고 카드 각도에 따라 움직인다.

### 홀로그램

- 개별 카드의 기본 홀로그램 확률: 10%
- 카드팩의 기본 홀로그램 확률: 1%
- 홀로그램 팩에서 나오는 모든 카드는 홀로그램이 된다.
- 홀로그램 카드는 기본 점수를 한 번 더 획득한다.
- 덱 안에서는 같은 카드를 2장 가진 것으로 취급해 능력 발동 횟수도 증가한다.
- 일부 룬과 마녀 능력은 카드 또는 팩의 홀로그램 확률을 높인다.

### 현재 콘텐츠 규모

| 등급 | 카드 수 |
|---|---:|
| 일반 | 14 |
| 고급 | 13 |
| 희귀 | 12 |
| 영웅 | 12 |
| 전설 | 4 |
| 합계 | 55 |

현재 전설 카드는 `각성 용사`, `마공학 위성`, `세계수`, `자동 명시 종말장치`다. 전설은 일반 카드 프레임 대신 카드 전체를 차지하는 일러스트와 흰 글씨·검은 외곽선을 사용한다.

## 7. 점수 처리와 피드백

- 카드를 공개하면 등급 기본 점수 팝업이 카드 오른쪽에 나타난다.
- 덱 능력은 `카드명 +점수` 형식으로 발동 사유를 표시한다.
- 자연 연쇄로 발동하면 `자연-카드명` 형식으로 표시한다.
- 홀로그램 추가 점수는 `홀로그램!` 팝업으로 별도 표시한다.
- 획득 예정 점수는 총점 옆의 `+점수` 영역에 먼저 누적된다.
- 팝업 처리가 끝나면 0.5초 동안 총점과 라운드 점수에 반영된다.
- 다음 카드로 빠르게 넘기면 이전 카드의 미반영 점수를 즉시 반영한다.
- 대량 발동 시 팝업 속도를 높여 다음 카드 진행을 막지 않는다.

## 8. 덱 시스템

### 기본 규칙

- 덱 슬롯은 5개다.
- 빈 슬롯은 검은 카드 실루엣으로 표시한다.
- 공개한 카드를 넘길 때 빈 슬롯이 있으면 자동으로 덱에 보관한다.
- 현재 카드를 빈 슬롯으로 직접 드래그하면 해당 위치에 보관한 뒤 다음 카드로 진행한다.
- 현재 카드를 차 있는 슬롯에 드래그하면 덱 카드와 교체한다.
- 덱 카드를 드래그해 슬롯 순서를 바꿀 수 있다.
- 덱이 가득 찬 상태에서는 자동 보관하지 않으며 플레이어가 교체 여부를 결정한다.

### 카드 확인과 버리기

- 덱 카드를 클릭하면 배경이 어두워지고 카드를 크게 확인할 수 있다.
- 확대 상태에서도 카드 또는 빈 공간을 드래그해 카드를 회전할 수 있다.
- 확대 화면에서 등급, 이름, 설명, 태그, 현재 스택·누적 수치를 확인한다.
- `카드 버리기` 버튼은 확인 팝업을 거쳐 실행된다.
- 게임 오버와 팩 선택 화면에서도 덱을 확인할 수 있다.

### 덱 능력

- 덱에 보관된 카드와 그 카드에 장착·상속된 카드의 능력이 활성화된다.
- 능력 조건은 색, 숫자, 이전 카드, 발동 효과 수, 매 카드 공개, 팩 개봉 등으로 구성된다.
- 능력 결과는 고정 점수, 퍼센트 보너스, 누적 보너스, 스택 소비, 카드 생성, 홀로그램 부여, 성장 등으로 구성된다.
- 스택과 누적형 효과는 카드 설명 하단에 `n/목표`, `n점`, `n회` 형식으로 표시한다.

## 9. 주요 빌드 아키타입

### 자연 연쇄

- 자연 카드의 적합한 능력이 정상 발동하면 다른 자연 카드의 능력도 연쇄 발동한다.
- 팩 장수 증가, 팩 개봉 생성, 홀로그램 부여처럼 연쇄가 부적절한 유틸리티 능력은 제외한다.
- `큰 나무 정령`은 팩을 열 때 능력이 발동한 것으로 취급해 연쇄의 시작점이 될 수 있다.
- `세계수`는 다른 자연 카드 능력이 발동할 때마다 500점을 얻는 전설 피니셔다.

### 룬 공명

- 불룬, 물룬, 대지룬, 천룬 중 서로 다른 종류를 2종 이상 보유하면 공명한다.
- 같은 종류의 룬 여러 장만으로는 공명하지 않는다.
- 공명 중인 룬은 이름이 `카드명-공명`으로 표시된다.
- 공명 시 서로 다른 룬의 색 보너스와 홀로그램 확률 증가량을 합산한다.
- 설명에는 기본값과 공명 증가량을 `20%(+40%)`, `2%(+4%)`처럼 표시한다.

### 마법과 마법사

- `견습 마법사`, `마녀`는 마법을 1개 장착할 수 있다.
- 빈 슬롯을 가진 마법사가 덱에 있으면 새 마법 카드를 자동 장착한다.
- 반대로 마법이 먼저 덱에 있고 장착 가능한 마법사를 얻어도 자동 장착한다.
- 다른 마법을 드래그하면 기존 장착 마법과 교환할 수 있다.
- 마법은 숫자 스택, 팩 동안 유지되는 점수 보너스, 카드 생성 등 장기 엔진을 형성한다.

### 무기와 전사

- 암살자, 기사, 모험가, 용사, 각성 용사는 무기를 1개 장착할 수 있다.
- 장착과 교환 규칙은 마법과 동일하다.
- 장착 후 카드명은 `캐릭터명(장착 카드명)` 형태로 표시한다.
- 캐릭터와 장비를 함께 보관해 덱 슬롯 효율을 높이는 것이 핵심이다.

### 마공학 조립

- 마공학 나사: 최대 4장 합성
- 마공학 바퀴: 최대 2장 합성
- 마공학 배터리: 최대 2장 합성
- 마공학 엔진: 조립 핵심 재료
- 완성된 나사 4장, 바퀴 2장, 배터리 2장, 엔진 1장을 모두 보유하면 `마공학 위성`으로 자동 조립한다.
- 위성은 조립 전 유물의 모든 효과를 상속한다.
- 위성 자체는 다른 카드로 점수를 3번 획득할 때마다 400점을 획득한다. 카드의 등급 기본 점수도 횟수에 포함한다.

### 성장 영웅

- 모험가: 카드팩 5개 후 용사로 성장
- 용사: 카드 공개 시 200점을 얻으며, 카드팩 5개 후 각성 용사로 성장
- 각성 용사: 모든 카드에 100% 점수 보너스와 500점을 제공하는 전설 카드
- 성장 진행도는 덱 카드에 표시되고 팩 종료 시 갱신된다.

### 스택과 생성

- 숫자를 스택으로 모아 점수 또는 보너스로 바꾸는 마법 카드가 존재한다.
- `유성우`는 숫자 스택 17을 소비해 팩 맨 뒤에 유성을 생성하며 팩당 최대 7회 발동한다.
- 생성 카드는 즉시 현재 카드 뭉치의 맨 뒤에 포함된다.
- 태그 기반 생성은 현재 팩의 봉입률을 따른다.
- `가속 마법`은 같은 색 카드 공개 시 팩당 1회 무작위 일반 카드를 생성한다.

## 10. 태그 체계

현재 사용 태그:

- 자연
- 마법
- 룬
- 무기
- 마공학
- 전사
- 마법사

태그는 카드 분류 표시뿐 아니라 자연 연쇄, 룬 공명, 장착 가능 대상, 팩 개봉 시 특정 카드 생성 등에 사용한다. 한 카드는 여러 태그를 가질 수 있으며 설명 맨 윗줄에 `[태그, 태그2]` 형식으로 표시한다.

## 11. UI와 조작

### 기본 화면

- 중앙: 3D 카드팩 또는 현재 카드
- 왼쪽 아래: 5칸 덱
- 왼쪽: 접을 수 있는 조작법
- 점수 영역: 총점, 반영 예정 점수, 라운드 점수/요구 점수, 남은 팩 수
- 오른쪽 위: 설정 버튼

### 조작

| 입력 | 동작 |
|---|---|
| 팩 윗부분 드래그 | 팩 뜯기 |
| 카드 드래그 | 다음 카드로 넘기기 |
| 팩·카드 바깥 공간 드래그 | 3D 회전 감상 |
| 현재 카드→덱 드래그 | 보관 또는 교체 |
| 덱 카드→다른 슬롯 드래그 | 순서 변경 |
| 마법·무기→장착 가능 카드 드래그 | 장착 또는 교환 |
| 덱 카드 클릭 | 카드 확대 확인 |
| 팩 선택의 `?` 클릭 | 봉입 카드 확인 |

### 반응형 UI

- 가로·세로 화면을 모두 지원한다.
- 세로 화면에서는 카드, 팩, 덱과 점수 UI를 별도 배율과 위치로 배치한다.
- 카드와 팩의 회전 입력은 카메라 각도와 무관하게 자연스럽게 보이도록 정면 기준으로 보정한다.

### 설정과 접근성

- 한국어·영어 전환
- 전체 음량 조절
- 조작법 패널 열기·닫기
- 설정은 `PlayerPrefs`에 저장

## 12. 시각·사운드 방향

### 카드팩

- 본체 비율 약 1:1.8
- 얇고 납작한 유광 포장
- 옆으로 갈수록 얇아지는 실루엣
- 상단과 하단 마감이 본체에 자연스럽게 연결
- 찢김 시 절취선을 먼저 보여주지 않고 즉시 실제 오브젝트가 갈라지는 느낌

### 카드

- 팩 본체와 비슷한 크기의 얇은 단일 카드
- 모서리만 살짝 둥글게 처리
- 앞면은 색 배경, 등급 무늬, 숫자, 일러스트, 이름, 설명으로 구성
- 뒷면은 보라색 계열과 칠각성 모티프 사용
- 전설 카드는 프레임에 갇히지 않는 풀아트 구성

### 효과음

- 팩 뜯기
- 카드 등급별 공개
- 마법·무기 장착
- 룬 공명
- 점수 획득

## 13. 결과와 공유

- 게임 오버와 런 클리어 화면에서 최종 점수와 덱을 보여준다.
- 결과 화면의 덱 카드는 클릭해 확대 확인할 수 있다.
- 공유 버튼은 점수, 진행 라운드, 덱과 내부 누적 상태를 압축한 URL을 생성한다.
- 공유 링크를 연 사용자는 동일한 결과 화면과 덱을 읽기 전용으로 확인한다.
- 공유 받은 화면에는 재공유 버튼을 표시하지 않는다.
- `도전하기` 버튼으로 새 게임을 시작할 수 있다.

## 14. 기술 구성

- 엔진: Unity 6

## 15. 현재 밸런스 의도

- 초반에는 기본 점수와 단순 조건부 고정 점수가 중요하다.
- 중반에는 덱 5칸 제약을 장착과 합성으로 극복해야 한다.
- 후반에는 누적 퍼센트, 자연 연쇄, 룬 공명, 성장·조립 전설 카드가 주요 고점 수단이 된다.
- 팩 선택은 현재 덱의 태그와 필요한 합성 재료를 기준으로 결정하게 한다.
- 홀로그램은 단순 점수 2배뿐 아니라 덱 능력 복제 효과를 제공해 런의 방향을 바꾸는 희귀 사건으로 사용한다.

## 16. 확인이 필요한 기획 항목

아래 항목은 현재 구현값을 유지하고 있지만 정식 밸런싱 전에 결정이 필요하다.

1. **전설 기본 점수**: 현재 영웅과 동일한 500점이다. 전설의 희소성에 맞춰 별도 점수를 줄지 검토한다.
2. **전설 획득 경로**: 일반 팩의 전설 봉입률은 현재 0%다. 성장·조립 외 전설의 직접 등장 방식을 정해야 한다.
3. **일상의 일화 장수**: 다른 팩보다 2장 많은 7장이라 점수와 덱 성장 기대값이 높다. 저등급 전용이라는 약점이 충분한지 측정한다.
4. **영웅 새로운 팩**: 선택 가중치 0.1, 1장 구성, 영웅 100%다. 등장 체감과 기대 점수를 실제 플레이로 검증한다.
5. **자연 연쇄 상한**: 자연 카드 수가 늘수록 발동량이 급격히 증가할 수 있으므로 팝업 수, 처리 시간, 점수 상한을 측정한다.
6. **홀로그램 복제**: 합성 카드와 홀로그램 복제가 결합될 때 능력 배수가 과도해지는지 확인한다.
7. **팩 간 차별화**: 카드 수가 유사한 팩은 테마 전용 카드와 가중치로 선택 의미를 더 강화한다.
8. **런 길이**: 최대 18팩이 웹게임 한 세션에 적절한지 평균 플레이 시간을 측정한다.

## 17. 프로토타입 완료 기준

- 팩 선택부터 개봉, 카드 공개, 점수 획득, 덱 편집, 라운드 판정까지 한 런이 중단 없이 진행된다.
- 가로·세로 화면에서 핵심 UI와 3D 오브젝트가 겹치거나 잘리지 않는다.
- 카드 55장과 팩 8종이 데이터 기반으로 정상 추첨된다.
- 자연, 룬, 마법·무기 장착, 마공학 조립, 성장, 홀로그램 빌드가 각각 완주 가능한 전략으로 작동한다.
- 한글·영문 전환 후 카드 이름과 설명이 카드 영역 안에서 정상 표시된다.
- WebGL 빌드가 GitHub Pages에서 검은 화면이나 누락 셰이더 없이 실행된다.
- 게임 오버·클리어 결과를 공유하고 공유 링크에서 덱을 확인할 수 있다.
